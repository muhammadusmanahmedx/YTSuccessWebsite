# YT Success Studio — Brand Website

Marketing site for **YT Success Studio**: home, about, services, and contact (WhatsApp + email). Built from the Crypgo shadcn landing template, rebranded to match the mobile/web apps.

## Stack

- Next.js (App Router) + Tailwind CSS v4 + shadcn/ui
- Framer Motion animations
- Brand fonts: Sora + Manrope
- Colors from the apps (`#f52027` primary, `#0b0707` background)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Configure

Edit `src/lib/site.ts` for:

- WhatsApp number
- Email
- Play Store / App Store URLs
- Services copy & testimonials

## App mockups

Place screenshots in `public/images/mockups/` — see that folder’s README for filenames. Phone frames are already wired on Home and Services.
